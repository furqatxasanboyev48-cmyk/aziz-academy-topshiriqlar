# Shaxsiy vizitka
'Run' tugmasi sahifani jonli ko'rsatadi.
Bu loyiha shaxsiy ma'lumootlar, ko'nikmalarini
jamlagan oddiy web - vizitka.U HTML va CSS texnalogiyalari 
yordamida yaratilgan bo'lib, foydalanuvchiga o'zi haqida 
qisqacha ma'lumot berish imkonini beradi. Loyiha ishga
tushishi uchun 'index.html' faylini istalgan zamonaviy
brauzerdan ochish kifoya qiladi!
